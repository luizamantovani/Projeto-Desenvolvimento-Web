Sobre HTML, CSS e JavaScript

Este projeto foi desenvolvido utilizando três tecnologias fundamentais do desenvolvimento web.

HTML

O HTML (HyperText Markup Language) é responsável pela estrutura do site. Ele define os elementos da página, como títulos, parágrafos, imagens e botões.

CSS

O CSS (Cascading Style Sheets) é utilizado para estilizar o site. Com ele, é possível definir cores, fontes, espaçamentos e deixar a página mais bonita e organizada.

JavaScript

O JavaScript é responsável pela interatividade do site. Ele permite criar ações dinâmicas, como cliques em botões, animações e integração com outros sistemas.
